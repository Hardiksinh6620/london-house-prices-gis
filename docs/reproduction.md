# Reproduction requirements

Recover the original GIS project, input datasets, metadata, and analysis records before claiming to rerun the study. Record software versions, coordinate systems, units, field definitions, and exact data vintages. Compare one output against the report and document differences before extending the work.

The repository currently supports reading the report and running a limited educational check. It does not reproduce the original spatial analysis. Acceptance of a later reproduction requires traceable inputs, runnable steps, documented settings, useful validation, and a clear statement of which results match or differ. Replacement data and new methods must be labelled as later work.
